# duda-nails
## Sobre o projeto
O Duda Nails é um sistema para gerenciamento deum salão de unhas.

O projeto tem como objetivo organizar informações sobre clientes, serviços e agendamentos, facilitanto a organização e o controle do salão.

## objetivo
Criar um banco de dados para amarzenar e organizar as informações do salão Duda Nails.

## O que são ultilizdos
-PostgreSQL
-SQL
-GitHub

## Banco de Dados
O banco de dados será criado ultilizando PostgreSQL e terá tabelas relacionadas ao fucionamento do salão.

O arquivo .sql` contem a criação do banco, das tabelas e alguns dados de exemplo.

## Projeto
Sistema de gerenciamento para o salão Duda Nails.
