# Duda Nails

## Sobre o projeto

O Duda Nails é um sistema para o gerenciamento de um salão de unhas.

O projeto tem como objetivo organizar as informações sobre clientes, serviços e agendamentos, facilitando a organização e o controle do salão.

## Objetivo

Criar um banco de dados para armazenar e organizar as informações do salão Duda Nails.

## Tecnologias utilizadas

* PostgreSQL
* SQL
* GitHub

## Banco de Dados

O banco de dados será criado utilizando PostgreSQL e terá tabelas relacionadas ao funcionamento do salão.

O arquivo `init.sql` contém a criação das tabelas e alguns dados de exemplo para iniciar o banco de dados.

## Projeto

Sistema de gerenciamento para o salão Duda Nails, com foco no cadastro de clientes, nos serviços oferecidos e nos agendamentos.
